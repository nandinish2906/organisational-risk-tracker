# Security Policy

## Supported Versions

This is an educational project and is maintained for learning and demonstration purposes.

Version : Current version on the main branch

Supported ✅


Security fixes and updates may be made as the project is maintained. No formal long-term support is guaranteed.


## Reporting a Vulnerability

If you discover a security vulnerability in the Organisational Risk Tracker, please report it privately to the repository maintainer rather than publishing sensitive technical details in a public issue.

Include:
- A description of the potential vulnerability.
- Steps to reproduce the issue.
- The potential impact.
- Any suggested remediation.

Please do not include real user data, passwords, database URLs, or other secrets in reports.

## Scope

This is an educational project. It should not be assumed to be production-ready or suitable for handling sensitive organisational data without further security review.
